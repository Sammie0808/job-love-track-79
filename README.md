# HireMe: Your Job Tracker

Create a modern job application tracker called "HireMe" with a clean, minimal design.

Features:

- Add job applications: company name, role, date applied, status

- Status categories: Applied, Interview, Offer, Rejected

- Set reminders for follow-up emails and interviews

- Upload CV and cover letter for each application

- Dashboard showing total applications and interview rate

Design Requirements:

- Mobile-friendly and responsive layout

- Modern interface with easy navigation

- Professional color scheme: navy blue, white, and grey

- Clean dashboard with progress bars

Tech: Build with React + Tailwind CSS. Save data in browser local storage.

Add analytics to show applications per month and success rate.
